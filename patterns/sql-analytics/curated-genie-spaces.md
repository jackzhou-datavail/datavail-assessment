# Curated Genie Spaces

**Category:** SQL & Analytics

A Genie space answers questions for one topic and one audience, over a
handful of well-documented tables, with metrics expressed as SQL
instructions and recurring questions pinned as trusted assets — rather
than being pointed at a schema and asked to answer anything.

## Why it matters

Databricks' framing is the useful one: treat Genie "as a new data
analyst joining your company" who needs "clear context to be
effective." No analyst, however capable, does well when handed fifty
unfamiliar tables and an open-ended remit — and the fix is the same in
both cases, which is scope and documentation.

The guidance is specific about scope. "Start as small as possible, with
minimal instructions and a limited set of questions to answer," aiming
for **five or fewer tables**, and "the more focused your selection, the
better." There is a hard ceiling (50 tables or views per agent), but
the recommendation sits far below it, and where a topic genuinely needs
more, the answer is to "prejoin related tables into views or metric
views before adding them."

Accuracy depends on structure over prose. The instruction hierarchy is
explicit: **SQL expressions first**, example SQL queries second, plain
text instructions only "when SQL methods [are] insufficient." Text
instructions are where conflicting guidance accumulates.

## What good looks like

- One space per topic and audience, with the audience named — an agent
  "should answer questions for a particular topic and audience, not
  general questions across various domains."
- Underlying tables well annotated, since Genie reads Unity Catalog
  column names and descriptions to build its answers. See
  [`documented-tables-and-columns.md`](documented-tables-and-columns.md).
- Metrics, filters, and dimensions defined as SQL expressions; complex
  multi-part logic demonstrated with example queries.
- **Trusted assets** — parameterized example queries and UC-registered
  functions — for "well-established recurring questions," so anticipated
  questions get verified answers flagged as trusted in the response.
- A curator who is "a data analyst proficient in SQL" and knows the
  domain, not a platform admin configuring it generically.
- **Benchmark questions** used to score accuracy systematically, with
  the author as first user, reading the generated SQL rather than
  eyeballing the answer.
- Business-user testing, scoped to the topic the agent is for, with a
  feedback path back to the authors.
- Ongoing monitoring through the Monitoring tab and audit logs, and
  deployment through Declarative Automation Bundles so the space is
  versioned rather than clicked together.
- Column synonyms, agent-scoped descriptions, and prompt matching used
  to bridge business vocabulary and column names.

## How to detect

Genie space configuration is read through the Genie API or the space
UI: table count per space, presence of SQL-expression instructions
versus free-text ones, count of trusted assets, and whether benchmarks
exist. Combine with `system.information_schema.columns.comment`
coverage over the space's tables, since undocumented columns cap
achievable accuracy regardless of instructions. Usage and question
volume appear in the Monitoring tab, and query activity generated by
the space lands in `system.query.history` and `system.access.audit`.
